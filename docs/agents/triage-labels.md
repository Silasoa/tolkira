# Triage Labels

| Label | Meaning |
|---|---|
| `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | Waiting on the reporter for information |
| `ready-for-agent` | Fully specified, ready for an agent |
| `ready-for-human` | Requires human implementation or judgement |
| `wontfix` | Will not be actioned |

A change reaches `ready-for-agent` only after the spec is approved and the
acceptance criteria are testable.
