## RED reasons

### Unit tests

Command:

```
npx vitest run test/playwright.test.ts test/render-attachments.test.ts test/cli-edge.test.ts test/compat-attachments.test.ts
```

Result: 4 files failed, **13 failed | 57 passed | 2 skipped (72)**.

Adapter (`test/playwright.test.ts`) — all fail because
`parsePlaywrightJson` still returns `Envelope[]`, so the documented
`{ envelopes, skippedAttachments }` shape yields `undefined`:

- `counts a final-attempt path attachment outside the input folder and cwd`:
  `expected undefined to be 1`.
- `does not count a relative attachment that resolves through the working
  directory`: `expected undefined to be +0` (embedding is already covered by
  the existing cwd test).
- `does not count an outside path when an inline body is present`:
  `expected undefined to be +0`.
- `does not count missing, directory, URL-scheme or UNC attachment paths`:
  `expected undefined to be +0`.
- `does not count trace zips or earlier-attempt attachments`:
  `expected undefined to be +0`.
- `sums skipped attachments across inputs and counts a duplicate input once`:
  `expected undefined to be 2` (`GeneratedReport` has no
  `skippedAttachments`).
- `does not count a symlinked attachment path`: skipped on win32, matching the
  existing symlink case; it runs on POSIX CI.

Render (`test/render-attachments.test.ts`) — all fail because the shell and
the footer are not implemented:

- singular: `expected undefined to be '1 path attachment was skipped: it is .'`

  Tolkira. Single file. No.'` (footer still says
  `Screenshots are embedded.`).
- notice footer: same neutral-footer failure.

CLI (`test/cli-edge.test.ts`):

  `expected '' to be 'tolkira: warning: 1 path attachment w.'` (stderr is

  `expected '' to contain '1 path attachment was skipped'`.
- `does not warn for a JSON-only run with a skipped attachment`: green guard
  (stdout JSON-only, stderr empty).
- `does not warn when every attachment is embedded`: green guard.

Compat (`test/compat-attachments.test.ts`):

  `expected [] to include '1 path attachment was skipped: it is .'`.
- `adds no attachment warning for a clean run`: green guard.

### Browser test

Command:

```
npx playwright test test/e2e/report.spec.ts -g "attachment warning" --project=chromium
```

Result: **1 failed**.

`shows an attachment warning on both tabs at 1440 and 320 px` fails at
`await expect(page.locator('.attachmentWarning')).toBeVisible()` with
`element(s) not found`. The test then covers both tabs and widths, the 1 px
edge alignment against `.runHead`, page overflow <= 1 and 320 px at
`document.documentElement.style.fontSize = '32px'`.

## Notes for the implementer

- The shared copy in `test/attachments.ts` is the exact text from the design;
  render/browser tests decode HTML entities before comparing, CLI and compat
  compare plain text.
- The two-input test builds two distinct files in one directory and a
  duplicate-input test passes the same file twice; both rely on the existing
  content-hash dedupe.
- The trace/earlier test uses retry 0 with an outside path and retry 1 with a
  trace zip, so neither may be counted.
